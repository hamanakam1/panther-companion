# Security Policy

## Supported versions

Only the latest release on `main` is supported with security fixes.

## Reporting a vulnerability

Please do **not** open a public issue for security vulnerabilities. Instead, email
mike@sjultra.com with a description, reproduction steps, and impact. You will receive
an acknowledgment within 72 hours.

Panther Companion is local-first: state, history, preferences, and models stay on-device
unless you explicitly opt into a cloud path. Reports involving data leaving the device
without explicit consent are treated as high severity.
